# My TodoList

A simple and beginner-friendly Todo List web application that helps users add, manage, and remove daily tasks.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean user interface
- Works directly in the browser

## Technologies Used

- HTML
- CSS
- JavaScript
